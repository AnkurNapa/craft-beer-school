ವಾರ 01. Brewery data model
  • Dashboard ಗೆ floor ನಿಂದ ಏನು ಬೇಕು: batch codeಗಳು, ದಿನಾಂಕಗಳು, volumeಗಳು, gravityಗಳು, ನಷ್ಟಗಳು
  • Brew log ಸ್ವಚ್ಛಗೊಳಿಸುವುದು: ಪ್ರತಿ batch ಗೆ ಒಂದು row, ಪ್ರತಿ column ಗೆ ಒಂದು unit, merged cellಗಳಿಲ್ಲ
  • Batch code ಮೇಲೆ brew, cellar, packaging ಮತ್ತು sales data ಜೋಡಿಸುವುದು
  • Power BI: Power Query, data model ಮತ್ತು ನಿಮ್ಮ ಮೊದಲ DAX measure
  • Tableau: connect ಮಾಡುವುದು, join ಮಾಡುವುದು ಮತ್ತು ನಿಮ್ಮ ಮೊದಲ calculated field
  • Brewhouse yield, beer loss ಮತ್ತು tank occupancy measureಗಳಾಗಿ, formulaಗಳೊಂದಿಗೆ

ಅಭ್ಯಾಸ ಕಾರ್ಯ: ಕಳೆದ ತ್ರೈಮಾಸಿಕದ brew log ಅನ್ನು Power BI ಅಥವಾ Tableau ಗೆ load ಮಾಡಿ ಪ್ರತಿ batch ನ yield ಅನ್ನು screen ಮೇಲೆ ತನ್ನಿ.

ವಾರ 02. ಜನರು ತೆರೆಯುವ dashboardಗಳು
  • ಒಂದು ಪುಟ, ಐದು ಸಂಖ್ಯೆಗಳು: volume, yield, loss, tank ನಲ್ಲಿ ದಿನಗಳು, ಏನು ಮಾರಾಟವಾಯಿತು
  • Control limitಗಳೊಂದಿಗೆ fermentation curveಗಳು ಮತ್ತು quality trendಗಳು
  • Production ಪಕ್ಕದಲ್ಲಿ sales ಮತ್ತು depletionಗಳು, ಇದರಿಂದ stock ನಿಮ್ಮನ್ನು ಅಚ್ಚರಿಗೊಳಿಸುವುದು ನಿಲ್ಲುತ್ತದೆ
  • Power BI ಮತ್ತು Tableau: licensing, sharing, refresh ಮತ್ತು ಪ್ರತಿಯೊಂದರ ತೊಂದರೆ ಎಲ್ಲಿ
  • ಪ್ರತಿ ಸೋಮವಾರ ಯಾರೋ ಮರುಟೈಪ್ ಮಾಡದೆ data refresh ಮಾಡುವುದು
